# Character Map Keyboard

A standard-library Tkinter character map with a built-in text editor. It makes common technical, Greek, mathematical, unit, currency, arrow, and symbol characters quick to insert or copy.

Run it with Python 3:

```powershell
python character_map_keyboard.py
```

## Use

- Search by name or filter by category.
- Left-click a symbol to insert it into the document at the cursor.
- Right-click a symbol to copy it to the clipboard, then paste it into another application with `Ctrl+V`.
- The Recent row keeps the last eight chosen symbols available.
- Open and save UTF-8 text files from the File menu.
